⚠️ Koneksi Database Belum Dikonfigurasi

Aplikasi belum bisa terhubung ke database di hosting ini. Ini biasanya terjadi karena file konfigurasi database khusus server ini belum dibuat.

  1. Masuk ke cPanel → MySQL Databases, pastikan database master dan database bisnis sudah dibuat, beserta user MySQL dengan akses penuh ke keduanya.
  2. Lewat cPanel File Manager, salin config/local-db-config.example.php menjadi config/local-db-config.php (jangan lewat git).
  3. Isi 4 nilai di file tersebut (DB_HOST, DB_NAME, DB_USER, DB_PASS) sesuai info dari cPanel.
  4. Import file .sql backup ke database yang sudah dibuat lewat phpMyAdmin.

Setelah selesai, muat ulang halaman ini atau kembali ke halaman utama.
